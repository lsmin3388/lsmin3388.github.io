사물함 통합 관리 서비스

역할인프라 · 백엔드
기간2024 · 경북대 컴퓨터학부

배경

학과 사물함 배정·관리 웹 서비스. 클라우드 대신 학과 물리서버에 직접 구축.

문제

수기 배정으로 충돌과 분실이 잦음. 서비스를 올릴 서버 인프라도 없음.

해결

Ubuntu 22.04 물리서버 세팅. ufw 방화벽, Nginx 리버스 프록시, SSL 인증서, Docker 컨테이너 직접 구성 후 Spring Boot 사물함 서비스 배포.

성과

사물함 배정·조회 디지털화. 인프라부터 서비스까지 단독 구축·운영.

기술 스택

Spring BootMySQLUbuntu 22.04DockerNginxSSL · ufw
