Project · 인프라

사물함 통합 관리 서비스

역할인프라 · 백엔드
기간2024 · 경북대 컴퓨터학부

배경

학과 사물함 관리 웹 서비스를 학과 물리서버 위에 직접 구축했습니다.

문제

사물함 배정이 수기로 이뤄져 충돌·분실이 잦았고, 서버 인프라가 없었습니다.

해결

Ubuntu 물리서버에 방화벽·Nginx·SSL·Docker로 인프라를 구성하고 Spring Boot 서비스를 배포했습니다.

성과

학과 자체 인프라 위에서 사물함 배정·조회를 디지털화, 인프라부터 서비스까지 단독 구축했습니다.

기술 스택

Spring BootMySQLUbuntu 22.04DockerNginxSSL · ufw
