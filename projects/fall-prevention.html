낙상 예방 어시스턴트

산학

역할서버 · Android · 인프라 개발 총괄
기간2024.07 ~ 2025.03 · 해피에이징

요약

해피에이징 산학 프로젝트. 고령자 가정의 낙상 위험을 집 안 사진과 건강 설문으로 점검하는 서비스. 서버·Android 앱·인프라 개발 총괄. Google Play 출시(현재 서비스 종료).

주요 업무

  • 집 안 사진을 OpenAI 비전 모델로 방별 분석해 위험 요소 탐지
  • 건강 설문 응답을 KMeans로 군집화해 위험 등급 산정, 맞춤형 안전 보고서(PDF) 생성 기능을 FastAPI 서버로 서비스화
  • 서버를 6개 Gradle 모듈로 분리하고 OpenAI 연동을 분석 모듈에 격리
  • 브랜치별 CI/CD: PR 빌드, 운영 브랜치 푸시 시 Docker 이미지 배포, 운영에서 메인으로 자동 동기화
  • Android 앱(Kotlin) 주 개발. 고해상도 사진을 5MB 이하로 줄이는 업로드 처리, 토큰 재발급 시 인증 헤더가 중복되던 버그 수정

기술 스택

  • 서버: Spring Boot, JPA, PostgreSQL
  • AI: OpenAI, Python, FastAPI
  • 앱: Kotlin(Android)
  • 인프라: Docker, GitHub Actions, AWS EC2
