경북대 대동제 80주년 웹앱

역할풀스택 개발 · 프로덕션 운영
기간2026.04 — 05 · 경북대학교 2026 대동제

배경

경북대학교 80주년 대동제(2026.05.20–22)에서 실제 관람객이 사용한 모바일 웹앱입니다. 부스·주막 정보, 온라인 대기열, 실시간 부스 랭킹, 롤링페이퍼, 랜덤 매칭을 제공합니다.

문제

수천 명이 몰리는 축제 현장의 대기·정보·참여를, 한 번에 견디는 실서비스로 풀어야 했습니다.

해결

React 19 + Spring Boot 3.5 풀스택으로 구축했습니다. 전화 인증·SMS 호출 알림 기반 온라인 대기열, SSE·Redis 실시간 부스 랭킹, 시간대별 랜덤 매칭(공정성 알고리즘), 관리자 콘솔을 구현하고, Docker Compose·GitHub Actions로 학과 서버에 배포·운영했습니다.

성과

대동제 사흘간 실제 운영 — 부스 59개, 롤링페이퍼 100보드, 실대기·매칭 데이터를 처리했습니다. 약 1,500 동시 접속을 대비해 용량을 설계하고, 런북·모니터링·장애 대응까지 프로덕션 운영을 맡았습니다. 백엔드 커밋의 약 53%를 담당한 최다 기여자였습니다.
