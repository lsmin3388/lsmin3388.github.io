기간2026.01 ~ 02 · DataHouse Vietnam, 다낭

배경

베트남 다낭 DataHouse Vietnam 해외 인턴십에서 개발한 Slack 협업 챗봇.

문제

팀 투표와 일정 조율이 Slack 안팎으로 흩어져 맥락이 끊기고 기록이 남지 않음.

해결

Slack 안에서 투표 생성과 일정 관리가 되는 챗봇을 Node.js·TypeScript로 개발. DB 쿼리와 UI 흐름 동시 최적화.

성과

응답시간 38% 단축. 의사결정과 일정 관리를 Slack 안에서 마무리.

기술 스택

Node.jsTypeScriptPostgreSQLSlack API
