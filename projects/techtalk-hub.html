역할백엔드 개발자(인턴)
기간2026.01 ~ 02 · DataHouse Vietnam, 다낭

요약

DataHouse Vietnam 인턴십에서 개발한 Slack 기술 발표 챗봇. 발표 주제 제안, 주간 가중 투표, 우승 발표의 Google Calendar 자동 등록 지원. 프로젝트 초기 구조, DB 스키마, CI와 배포 구성 담당.

해결한 문제

  • Slack 3초 응답 제한: 요청을 먼저 수신 확인하고 로딩 모달을 띄운 뒤 화면을 갱신하는 방식으로 타임아웃 해결
  • 가중 투표(주당 3포인트) 정합성: 포인트 차감을 트랜잭션 안에서 처리하고 제안 철회 시 환불
  • Slack 블록 100개 제한: 리더보드를 모달과 페이지네이션으로 전환
  • Gemini 자동 태깅 비용 관리: 경량 모델, 프롬프트 축약, 캐싱과 호출 제한 적용
  • DB 쿼리 최적화와 인메모리 캐시로 응답시간 38% 단축

기술 스택

  • Node.js, TypeScript, Slack Bolt
  • Prisma, PostgreSQL(Supabase)
  • Gemini API, Google Calendar API, Docker
