실시간 주식 데이터 파이프라인

역할DevOps · 서버 개발자
기간2023.06 — 2024.03 · 주식·금융 교육 스타트업

배경

주식·금융 교육 스타트업의 모의투자 서비스에서 시세 처리를 담당했습니다.

문제

기존 모놀리식 구조는 수천 종목의 실시간 데이터를 동시에 처리하지 못했습니다.

해결

Spring WebFlux · RabbitMQ · InfluxDB 기반 MSA로 재설계했습니다.

성과

3,000+ 종목의 동시 WebSocket 연결을 1초 미만 지연으로 처리했습니다.
