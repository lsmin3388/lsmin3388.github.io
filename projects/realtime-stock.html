Project

실시간 주식 데이터 파이프라인

역할DevOps · 서버 개발자
기간2023.06 ~ 2024.03 · 주식·금융 교육 스타트업

배경

주식·금융 교육 스타트업의 모의투자 서비스 시세 처리 담당. 코스피·코스닥 전 종목(3,000+) 실시간 시세 대상.

문제

모놀리식 구조로는 수천 종목의 실시간 데이터 동시 처리 불가. 트래픽이 몰리면 지연과 장애가 서비스 전체로 확산.

해결

Spring WebFlux 리액티브 처리, RabbitMQ 메시지 큐, InfluxDB 시계열 저장 기반 MSA로 재설계. WebSocket으로 실시간 시세 푸시, 도메인별 서비스 분리로 장애 격리.

성과

3,000+ 종목 동시 WebSocket 연결을 1초 미만 지연으로 처리. 부하가 몰려도 서비스 단위로 확장·격리 가능한 구조 확보.

기술 스택
