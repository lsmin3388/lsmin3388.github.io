03. Projects

Featured

Real-time Stock Data Pipeline

Real-time price pipeline for 3000+ KOSPI/KOSDAQ stocks. Rewrote the whole thing from a monolith to MSA because the old system just couldn't keep up.

Problem

Legacy monolithic system couldn't handle real-time data for thousands of stocks simultaneously.

Solution

Redesigned as MSA using Spring Webflux for reactive processing, RabbitMQ for message queuing, and InfluxDB for time-series data.

Impact

Successfully handled 3000+ concurrent WebSocket connections with sub-second latency.
